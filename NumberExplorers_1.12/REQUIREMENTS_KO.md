# 숫자 탐험대 1.12 — 목표와 요구사항

**단일 목표:** 초등 저학년 플레이어가 수의 증가·감소 규칙을 발견하고 다음 숫자를 예측하게 한다. 플레이어 한 명이 유일한 액터이며 온라인 상대방은 범위 밖입니다.

| ID | 기능 요구사항 | 구현 | 검증 |
| --- | --- | --- | --- |
| FR-01 | 다음 숫자를 선택한다 | 기차 10개 역, 세 단계 난이도, 무작위 시작과 변화 폭 | 난이도별 100회 생성·정답 검사 |
| FR-02 | 규칙을 스스로 찾고 피드백을 받는다 | 보통·어려움에서는 변화량 숨김, 오답 후 변화량 힌트 | 한·영 화면·입력 테스트 |
| FR-03 | 어려운 규칙을 복습한다 | 수열·369·계산 오답노트와 이전 저장 호환 | 기록·복습·V8/V9 왕복 |
| FR-04 | 다른 게임을 찾는다 | 369 한 카드→규칙 선택, 사칙연산 한 카드→연산 선택, 하노이·31·점 잇기 | 전체 메뉴 진입 테스트 |
| FR-05 | 하노이 도전 결과를 이해한다 | 원판 3·5·7 × 막대 3·4·5, 이동 수/최소 수/최단 힌트 | 9조합 최단 완료 테스트 |
| FR-06 | 기존 자산을 이어받는다 | 코인·캐릭터·배경·출석·기존 오답, V1~V9 저장 호환 | 옛 저장 읽기·설정만 초기화 |

주된 플레이 흐름은 **규칙 관찰 → 다음 숫자 예측 → 기차 이동 → 오답 복습**입니다. 369 박수전·사칙연산·하노이 등은 별도 ‘다른 게임’에 모았습니다. 수학 학습 효과나 재방문 성과는 아직 사용자 조사로 검증하지 않았습니다. C+SDL2는 기존 소스와 그래픽·입력·오디오 코드를 재사용하고 규칙 계산과 화면을 분리해 Windows 실행 파일로 배포하기 위해 사용했습니다.
