# 숫자 탐험대 1.12 — 숫자 기차

Windows 64비트용 게임입니다. ZIP을 **모두 압축 해제**하고 `NumberExplorers.exe` 또는 `RUN.bat`를 더블클릭하세요. `Assets`와 SDL2 DLL 세 개를 EXE 옆에 두어야 합니다. 컴파일은 필요 없습니다.

## 숫자 기차

로비 → 싱글 플레이 → **숫자 기차**에서 난이도를 고른 뒤 무료로 시작합니다. 네 숫자를 보고 다섯 번째 숫자 레일을 고르면 기차가 다음 역으로 갑니다. 10개 역을 지나면 30코인을 받습니다. 틀려도 다시 고를 수 있고 그때부터 숫자 간 변화량이 표시됩니다. 게임 중 **설명 [F1]**로 방법을 볼 수 있습니다.

| 난이도 | 나오는 규칙 | 처음 보는 힌트 |
| --- | --- | --- |
| 쉬움 | 작은 수의 +1·+2·+3, 후반에는 간단한 빼기 | 숫자 사이 변화량 표시 |
| 보통 | 시작 숫자와 더하기/빼기 폭이 매번 달라지는 등차 규칙 | 변화량 숨김 |
| 어려움 | +1,+2,+3 또는 −8,−9,−10처럼 변화량 자체가 커지는 규칙, 출발 숫자·폭 무작위 | 변화량 숨김 |

문제는 플레이 때마다 새로 생성됩니다. 어려움의 예: `1 → 2 → 4 → 7 → ?`(11), `50 → 42 → 33 → 23 → ?`(12). 숫자 기차의 `3, 6, 9…`는 3씩 증가하는 수열이며, 369 박수 게임과 다른 규칙입니다.

## 다른 게임

369 박수 게임은 **카드 하나**에서 들어가 게임 시작 전에 **기본/아이템·이벤트전**을 고릅니다. 기본은 무료, 아이템전은 5코인입니다. **사칙연산**도 카드 하나에서 들어가 **더하기·빼기** 또는 **곱하기·나누기**를 탭으로 선택합니다. 하노이탑은 원판 **3·5·7개**와 막대 **3·4·5개**를 각각 선택할 수 있습니다. 화면에 현재 이동 횟수와 해당 조합의 최소 횟수를 보여 주고, 성공하면 실제 몇 번 옮겼는지 알려 줍니다. H는 현재 상태에서 목표까지의 최단 경로 힌트, U는 되돌리기입니다. 기존 31 게임과 숫자 점 잇기도 두 번째 ‘다른 게임’ 페이지에서 실행할 수 있습니다. **제로 게임은 제거했습니다.** 멀티 버튼은 ‘개발 중입니다’만 표시합니다.

## 오답노트·저장

기차에서 틀린 규칙은 수열 종류·첫 숫자·변화 폭·정답과 함께 오답노트에 저장됩니다. 369·사칙연산 오답도 함께 복습할 수 있습니다. 이전 버전의 제로 오답은 기존 기록을 잃지 않도록 읽고 복습할 수 있지만 새 제로 게임은 시작할 수 없습니다. 자주 틀린 문제가 먼저 나오고 복습은 무료입니다.

상점의 캐릭터 8종·배경 4종과 설정 초기화 시 자산을 보존하는 동작은 유지됩니다. 저장 경로 `%APPDATA%\CozyParty\369PartyLearning\save.txt`에서 V1~V8을 읽고 V9로 기록합니다. 업데이트 전 저장 파일을 복사해 백업하세요.

## 코드와 검증

`src/train.c`와 `src/train_ui.c`는 숫자 기차 규칙과 화면, `src/puzzles.c`와 `src/puzzle_ui.c`는 하노이/31/그림 퍼즐, `src/scene_menu.c`와 `src/learn_ui.c`는 묶인 메뉴, `src/save.c`와 `src/review.c`는 저장·복습을 담당합니다. 수정해 다시 빌드하려면 MSYS2 UCRT64 GCC에서 `BUILD_UCRT64.bat`를 실행하세요. 자산·라이브러리 저작권 정보는 `licenses`에 있습니다.

난이도별 수열 생성·오답·저장, 하노이 3~5막대와 3·5·7원판의 최단 힌트, 다른 모드 진입·보상·두 언어 화면을 검사했습니다. Windows x64 GUI EXE를 빌드했지만 실제 Windows PC에서 더블클릭 실행은 이 환경에서 검증하지 못했습니다.
