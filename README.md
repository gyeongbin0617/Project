# 🎮 369 PARTY - 프로젝트 저장소

전통 '369 게임'을 2지선다 조작([숫자] / [박수])과 타임어택, 그리고 탈락자 유령 방해 기믹으로 재해석한 **실시간 파티 퀴즈 액션 게임**입니다.

## 👥 팀원 및 역할
- **이현주** (제품 오너 / 팀장)
- **채정호** (보고서 작성자)
- **이기경** (메인 개발자)
- **백경빈** (보조 개발자 / GitHub 관리)
