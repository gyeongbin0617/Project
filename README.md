# 🎮 숫자 탐험대 (Number Explorers) - 프로젝트 저장소

숫자를 처음 접하는 아동이 복잡한 텍스트 설명 없이도 직관적인 시청각 인터랙션으로 수 개념을 익히고, 보상 수집을 통해 자발적으로 반복 학습할 수 있도록 설계된 **C / SDL2 기반 아동용 수 개념 학습 및 미니게임 프로젝트**입니다.

---

## ✨ 주요 게임 및 학습 콘텐츠 (v1.12)
* **🚂 숫자 기차 (메인)**: 수열의 숨어 있는 규칙을 찾아 다음 레일의 숫자를 맞히는 수 배열 학습 모드
* **👏 369 박수 게임**: 제한 시간 내 3·6·9 자릿수 판별 및 박수를 입력하는 기본 모드 & 특수 효과를 활용하는 아이템전
* **🧮 사칙연산**: 더하기·빼기·곱하기·나누기 단계별 기초 연산 학습 모드
* **🗼 하노이탑**: 원판과 막대 수를 선택해 규칙에 맞게 원판을 이동시키는 수 배열 퍼즐
* **🍦 배스킨라빈스 31**: AI 봇과 번갈아 숫자를 외치며 31을 피하는 수 전략 게임
* **🎨 숫자 그림 그리기**: 숫자 순서대로 점을 이어 숨겨진 그림을 완성하는 모드
* **💡 직관적 학습 보조 및 보상 시스템**: 그림 기반 `[F1]` 튜토리얼 설명창[cite: 9, 10, 11], 시각적 오답 교정 가이드, 코인 및 상점(캐릭터 스킨·배경 해금) 시스템
