# 📐 369 PARTY - 유스케이스 다이어그램 및 명세서

## 1. 유스케이스 다이어그램

- **주 액터 (Primary Actor)**: 유저 (아동, 학부모, 일반 플레이어)
- **보조 액터 (Secondary Actor)**: 실시간 멀티플레이 서버
- **주요 특징**: 2지선다 판정 연동(`<<include>>`) 및 탈락자 전용 유령 스킬 체계 구축

---

## 2. 유스케이스 명세서 (5종)

### 1) UC-01: 싱글 훈련 모드 플레이
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-01: 싱글 훈련 모드 플레이 |
| **액터명** | 유저 (아동 / 보호자 / 일반 유저) |
| **개요** | 유저가 2지선다 버튼을 이용해 3·6·9 수 순서에 맞게 입력하며 순발력을 훈련하는 단판 학습 모드 |
| **사전조건** | 메인 화면에서 '싱글 훈련 모드' 선택 완료 |
| **기본흐름** | 1. 시스템이 숫자를 1부터 순차적으로 제시한다.<br>2. 유저는 주어진 제한시간 내에 `[숫자(SPACE)]` 또는 `[박수(C)]` 버튼을 선택한다.<br>3. 시스템은 입력값의 정답 여부를 판정한다.<br>4. 정답 시 진행 숫자가 늘어나며 타임어택 제한 시간이 점진적으로 가속된다.<br>5. 라이프(하트)가 0이 되거나 제한 시간 초과 시 게임이 종료되고 결과 화면과 보상 코인이 표시된다. |
| **대체흐름** | **5a. 일시정지(ESC) 선택 시:** 게임이 일시 정지되며 메인 메뉴 이동 또는 재개 옵션이 제공된다. |
| **예외흐름** | **3a. 오답 입력 또는 시간 초과 시:** 하트(라이프)가 1 차감되고 오답 피드백 연출이 출력된다. |
| **사후조건** | 게임 결과(점수, 연속 기록) 산출 및 획득 코인 지급 |

### 2) UC-02: 2지선다 입력 및 판정
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-02: 2지선다 입력 및 판정 |
| **액터명** | 유저 (아동 / 보호자 / 일반 유저) |
| **개요** | 제시된 숫자에 3, 6, 9가 포함되었는지 판단하여 키보드/마우스 2지선다 입력을 처리하고 정/오답을 판정하는 모듈 |
| **사전조건** | 싱글 모드 또는 멀티 대전 인게임 진행 상태 |
| **기본흐름** | 1. 시스템이 현재 제시할 숫자 데이터(예: 33)를 화면에 렌더링한다.<br>2. 유저가 `[SPACE(숫자)]` 또는 `[C(박수)]` 키를 입력한다.<br>3. 시스템은 제시된 숫자의 3·6·9 포함 여부와 유저의 입력 타입을 실시간 비교 연산한다.<br>4. 판정 결과(정답/오답) 신호를 게임 루프 및 서버로 반환한다. |
| **대체흐름** | 해당 없음 |
| **예외흐름** | **2a. 입력 쿨타임 중 연타 발생 시:** 중복 입력 방지 로직이 작동하여 중복 키 입력을 무시한다. |
| **사후조건** | 입력 판정 결과에 따라 타임어택 타이머 갱신 또는 라이프 차감 이벤트 발생 |

### 3) UC-03: 코인 획득 및 상점 이용
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-03: 코인 획득 및 상점(작은 옷장) 이용 |
| **액터명** | 유저 (아동 / 보호자 / 일반 유저) |
| **개요** | 플레이 보상으로 수집한 코인을 사용하여 캐릭터 및 코스튬을 구매하고 착용하는 기능 |
| **사전조건** | 메인 화면에서 '상점(작은 옷장)' 메뉴 선택 완료 |
| **기본흐름** | 1. 시스템이 현재 유저의 보유 코인 수량과 상점 캐릭터/코스튬 목록을 표시한다.<br>2. 유저가 원하는 미해금 아이템을 선택하고 구매 버튼을 클릭한다.<br>3. 시스템은 보유 코인과 아이템 가격을 비교하여 코인을 차감하고 해금 상태로 변경한다.<br>4. 유저는 해금된 캐릭터/코스튬을 선택하여 장착을 완료한다. |
| **대체흐름** | **2a. 이미 보유한 아이템 선택 시:** 구매 버튼 대신 '장착하기' 버튼이 활성화되어 즉시 캐릭터 스타일을 변경한다. |
| **예외흐름** | **3a. 보유 코인이 부족한 상태에서 구매 시도 시:** "코인이 부족합니다" 알림 팝업이 출력되며 결제 처리가 취소된다. |
| **사후조건** | 유저 계정 데이터에 차감된 코인 수량 및 장착된 캐릭터 에셋 정보 반영 |

### 4) UC-04: 실시간 멀티 대전 참여
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-04: 실시간 멀티 대전 참여 |
| **액터명** | 주 액터: 유저 / 보조 액터: 실시간 멀티플레이 서버 |
| **개요** | 다른 플레이어와 방 매칭을 통해 실시간 턴 동기화 방식으로 369 대전을 진행하는 멀티플레이 모드 |
| **사전조건** | 네트워크 연결 정상 확인 및 멀티 대전 로비 진입 |
| **기본흐름** | 1. 유저가 '빠른 매칭' 또는 '방 생성'을 선택한다.<br>2. 서버는 대기 중인 유저들을 룸으로 매칭하고 게임 시작 신호를 전송한다.<br>3. 선(先) 플레이어 배정 카드 뽑기 및 진행 방향(시계/반시계) 카드가 추첨된다.<br>4. 유저들은 자신의 턴에 제한시간 내 2지선다 입력을 수행하며 실시간 턴 데이터를 주고받는다.<br>5. 최종 1인이 남을 때까지 대전이 진행되며 우승자와 순위에 따른 보상 코인이 지급된다. |
| **대체흐름** | 해당 없음 |
| **예외흐름** | **4a. 대전 중 특정 유저의 네트워크 이탈 발생 시:** 해당 유저는 즉시 기권(탈락) 처리되고 다음 플레이어로 턴이 강제 넘어가 대전이 지속된다. |
| **사후조건** | 대전 결과 저장 및 개인 승/패 기록, 보상 코인 지급 반영 |

### 5) UC-05: 유령(Ghost) 스킬 사용
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-05: 유령 스킬 사용 (방해 기믹) |
| **액터명** | 주 액터: 탈락한 유저 (유령 플레이어) / 보조 액터: 실시간 멀티플레이 서버 |
| **개요** | 멀티 대전에서 탈락한 플레이어가 관전 모드 이탈 없이 유령 상태로 남아 생존자를 방해하는 기능 |
| **사전조건** | 멀티플레이 대전 진행 중 라이프 소진으로 탈락 처리됨 |
| **기본흐름** | 1. 탈락한 유저는 유령 모드로 전환되며 유령 전용 방해 스킬 UI가 활성화된다.<br>2. 유저는 방해할 대상 생존자와 사용할 스킬(버튼 셔플 / 먹물 테러 / 시간 차감)을 선택한다.<br>3. 시스템(클라이언트)은 스킬 사용 신호를 서버로 전송한다.<br>4. 서버는 대상 플레이어에게 방해 패킷을 전달하여 해당 플레이어 화면에 방해 연출을 즉시 적용한다. |
| **대체흐름** | 해당 없음 |
| **예외흐름** | **2a. 스킬 쿨타임 중일 경우:** 스킬 클릭 시 재사용 대기시간 알람이 표시되며 스킬이 발동되지 않는다. |
| **사후조건** | 지정한 생존 유저의 화면/UI에 방해 효과 적용 |
