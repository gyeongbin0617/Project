# 📐 369 PARTY - 유스케이스 다이어그램 및 명세서

## 1. 유스케이스 다이어그램 개요

- **주 액터 (Primary Actor)**: 유저 (아동, 학부모, 일반 플레이어)
- **보조 액터 (Secondary Actor)**: 로컬 AI 봇 대전 엔진 (미소, 비비, 보모 등)
- **주요 특징**: 
  - 싱글 플레이 내 **대전 3종(기본 369, 아이템전, 탕수육)** 및 **학습 2종(더하기·빼기, 곱하기·나누기)** 통합
  - 2지선다 판정 연동(`<<include>>`) 및 로컬 AI 봇 턴 동기화 엔진 구현
  - *(※ 네트워크 멀티플레이 및 유령 방해 스킬은 v2.0 확장 목표로 정의)*

## 2. 유스케이스 명세서 (4종)

### 1) UC-01: 싱글 플레이 모드 (대전 & 학습)
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-01: 싱글 플레이 모드 (대전 & 학습) |
| **액터명** | 유저 (아동 / 보호자 / 일반 유저) |
| **개요** | 유저가 싱글 플레이 메뉴에서 대전 모드(기본 369, 아이템전, 탕수육) 또는 학습 모드(더하기·빼기, 곱하기·나누기)를 선택하여 플레이하는 기능 |
| **사전조건** | 메인 화면에서 '싱글 플레이' 메뉴 진입 완료 |
| **기본흐름** | 1. 유저가 대전 모드 3종 중 하나 또는 학습 모드 2종 중 하나를 선택한다.<br>2. 대전 모드 선택 시 AI 봇 인원수(1~3명)와 난이도를 설정하고 시작한다.<br>3. 학습 모드 선택 시 수 범위 또는 구구단 단수를 선택하고 원 세기 시각 힌트와 함께 문제를 풀이한다.<br>4. 게임/학습 완료 시 결과 화면이 출력되고 보상 코인을 지급받는다. |
| **대체흐름** | **2a. 학습 모드 중 구구단 확인 시:** '구구단' 버튼을 클릭해 전체 구구단 표 팝업을 확인 후 재개할 수 있다.<br>**4a. 일시정지(ESC) 선택 시:** 게임이 일시 정지되며 메인 메뉴 이동 또는 재개 옵션이 제공된다. |
| **예외흐름** | **3a. 대전 중 오답 입력 또는 시간 초과 시:** 하트(라이프)가 1 차감되고 오답 피드백 연출이 출력된다. |
| **사후조건** | 플레이 결과 산출 및 획득 코인 계정 데이터 반영 |

### 2) UC-02: 2지선다 입력 및 판정
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-02: 2지선다 입력 및 판정 |
| **액터명** | 유저 (아동 / 보호자 / 일반 유저) |
| **개요** | 제시된 숫자에 3, 6, 9가 포함되어 있는지 판단하여 키보드(`SPACE`/`C`) 또는 마우스 클릭 입력을 처리하고 정/오답을 판정하는 모듈 |
| **사전조건** | 대전 모드 인게임 진행 상태 |
| **기본흐름** | 1. 시스템이 현재 제시할 숫자 데이터를 화면에 렌더링한다.<br>2. 유저가 `[SPACE(숫자)]` 또는 `[C(박수)]` 버튼/키를 입력한다.<br>3. 시스템은 제시된 숫자의 3·6·9 포함 여부와 유저의 입력 타입을 비교 연산한다.<br>4. 판정 결과(정답/오답) 신호를 게임 루프 및 UI 연출 엔진으로 반환한다. |
| **대체흐름** | 해당 없음 (기본 판정 루프 수행) |
| **예외흐름** | **2a. 입력 쿨타임 중 연타 발생 시:** 중복 입력 방지(Debounce) 로직이 작동하여 중복 키 입력을 무시한다. |
| **사후조건** | 입력 판정 결과에 따라 타임어택 타이머 갱신 또는 라이프 차감 이벤트 발생 |

### 3) UC-03: 코인 획득 및 상점(작은 옷장) 이용
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-03: 코인 획득 및 상점(작은 옷장) 이용 |
| **액터명** | 유저 (아동 / 보호자 / 일반 유저) |
| **개요** | 플레이 보상으로 수집한 코인을 사용하여 8종의 동물 캐릭터를 해금하고 착용하는 기능 |
| **사전조건** | 메인 화면에서 '상점(작은 옷장)' 메뉴 선택 완료 |
| **기본흐름** | 1. 시스템이 보유 코인 수량과 상점 캐릭터 목록(1/2 페이지 총 8종)을 표시한다.<br>2. 유저가 미해금 캐릭터(버니, 미소, 비비, 보모, 여우 루비, 판다 핑이, 개구리 초롱, 코알라 코아 등)를 선택하고 구매 버튼을 클릭한다.<br>3. 시스템은 보유 코인과 가격을 비교하여 코인을 차감하고 해금 상태로 변경한다.<br>4. 유저는 해금된 캐릭터를 선택하여 장착을 완료한다. |
| **대체흐름** | **2a. 이미 보유한 캐릭터 선택 시:** 구매 버튼 대신 '사용 중 / 사용하기' 버튼이 활성화되어 즉시 캐릭터를 변경한다. |
| **예외흐름** | **3a. 보유 코인이 부족한 상태에서 구매 시도 시:** 코인 부족 알림 팝업이 출력되며 결제 처리가 취소된다. |
| **사후조건** | 차감된 코인 수량 및 장착된 캐릭터 에셋 정보 저장 |

### 4) UC-04: 로컬 AI 봇 제어 및 턴 동기화
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-04: 로컬 AI 봇 제어 및 턴 동기화 |
| **액터명** | 주 액터: 유저 / 보조 액터: 로컬 AI 봇 엔진 |
| **개요** | 유저가 설정한 AI 봇 친구들(미소, 비비, 보모 등)과 순서대로 턴을 교대하며 타임어택 제한시간을 동등하게 적용받는 턴제 대전 제어 모듈 |
| **사전조건** | UC-01 대전 모드 시작 시 봇 수 및 난이도 설정 완료 |
| **기본흐름** | 1. 시스템이 플레이어와 AI 봇들의 턴 순서를 배정하고 화면에 렌더링한다.<br>2. 현재 턴 플레이어(유저 또는 AI 봇)의 타임어택 타이머 바(Bar)를 가동한다.<br>3. AI 봇은 난이도 설정값에 따라 가상 반응속도 및 정답률 알고리즘을 수행하여 입력을 제출한다.<br>4. 한 플레이어의 턴이 끝나면 다음 플레이어로 턴을 동기화하여 전환한다. |
| **대체흐름** | 해당 없음 |
| **예외흐름** | **3a. AI 봇 오답 또는 시간 초과 시:** 해당 AI 봇의 하트가 차감되고 오답 안내 텍스트가 출력된다. |
| **사후조건** | 최후 1인 생존 시 대전 종료 및 승리 보상 산출 |
