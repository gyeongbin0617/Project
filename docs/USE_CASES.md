# 📐 369 PARTY - 유스케이스 다이어그램 및 명세서

## 1. 유스케이스 다이어그램 개요

- **시스템 경계**: 369 PARTY 게임 시스템[cite: 12]
- **주 액터 (Primary Actor)**: 아동 / 초등 저학년, 일반 유저[cite: 12]
- **보조 액터 (Secondary Actor)**: 학부모 / 교육자[cite: 12]
- **유스케이스 구성 및 연관 관계**:
  - **게임 플레이 (5종의 모드)**: 주 액터가 수행하며, `타이머 진행` 유스케이스를 필수 포함(`<<include>>`) 함[cite: 12].
  - **오답 교정 가이드 확인**: 게임 플레이 중 오답/타임아웃 발생 시 확장 실행(`<<extend>>`) 됨[cite: 12].
  - **상점 이용**: 주 액터가 수행하며, `캐릭터 해금` 유스케이스를 필수 포함(`<<include>>`) 함[cite: 12].
  - **AI 봇과 대전**: 주 액터가 수행함[cite: 12].
  - **플레이 기록 조회**: 아동/초등 저학년, 일반 유저, 학부모/교육자 액터가 수행함[cite: 12].

## 2. 유스케이스 명세서 (5종)

### 1) UC-01: 게임 플레이 (5종의 모드)
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-01: 게임 플레이 (5종의 모드)[cite: 12] |
| **액터명** | 아동 / 초등 저학년, 일반 유저[cite: 12] |
| **개요** | 유저가 5가지 게임 모드 중 하나를 선택하여 `SPACE(숫자)` / `C(박수)` 키 및 마우스 클릭을 활용해 369룰 판정을 진행하고 게임을 완료한다[cite: 12]. |
| **사전조건** | 시스템이 정상 구동되어 게임 메인 화면에 진입해 있어야 한다[cite: 12]. |
| **기본흐름** | 1. 유저가 원하는 게임 모드 중 1개를 선택한다[cite: 12].<br>2. 시스템이 게임 턴을 시작하고 Delta Time 기반 제한 시간 타이머를 작동시킨다[cite: 12].<br>3. 유저가 숫자에 맞춰 조작 키를 입력하거나 마우스로 클릭한다[cite: 12].<br>4. 시스템이 입력값의 정확성 및 쿨타임을 판정한다[cite: 12].<br>5. 올바른 입력 시 점수 획득 및 다음 턴으로 진행하며 난이도에 따라 타이머가 가속된다[cite: 12].<br>6. 게임 종료 조건 달성 시 최종 결과 UI를 출력하고 보상 코인을 지급한다[cite: 12]. |
| **대체흐름** | **[대체흐름 1A: 아이템/스킬 사용]** 유저가 파티 대전 모드 중 방해 스킬이나 아이템을 사용하면 즉시 제한 시간 갱신 또는 턴 스킵 효과를 적용한다[cite: 12]. |
| **예외흐름** | **[예외흐름 1E: 오답 발생]** 유저가 잘못된 키를 입력하거나 제한 시간을 초과한 경우 `UC-03(오답 교정 가이드 확인)` 유스케이스를 확장 실행한다[cite: 12]. |
| **사후조건** | 유저의 플레이 결과(점수, 맞힌 개수)가 저장되고 획득한 보상 코인이 유저 재화에 반영된다[cite: 12]. |

### 2) UC-02: 상점 이용
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-02: 상점 이용[cite: 12] |
| **액터명** | 아동 / 초등 저학년, 일반 유저[cite: 12] |
| **개요** | 유저가 게임 플레이를 통해 모은 보상 코인을 소비하여 원하는 동물 캐릭터를 해금하고 착용한다[cite: 12]. |
| **사전조건** | 유저가 시스템 메인 메뉴에서 상점 화면으로 진입한다[cite: 12]. |
| **기본흐름** | 1. 유저가 상점 메뉴를 선택하여 보유 코인 및 캐릭터 목록을 조회한다[cite: 12].<br>2. 유저가 해금하고자 하는 동물 캐릭터(8종 중 선택)를 클릭한다[cite: 12].<br>3. 시스템이 보유 코인 수량이 해금 가격 이상인지 검증한다[cite: 12].<br>4. 코인을 차감하고 캐릭터 해금을 완료한다[cite: 12].<br>5. 시스템이 해금 완료 시청각 연출을 제공하고 캐릭터를 즉시 착용 가능 상태로 변경한다[cite: 12]. |
| **대체흐름** | **[대체흐름 2A: 캐릭터 착용 변경]** 이미 해금된 캐릭터를 클릭할 경우 코인 차감 없이 해당 캐릭터를 인게임 대표 캐릭터로 즉시 장착한다[cite: 12]. |
| **예외흐름** | **[예외흐름 2E: 코인 부족]** 보유 코인이 부족한 경우 "코인이 부족합니다"라는 경고 팝업을 띄우고 구매 처리를 취소한다[cite: 12]. |
| **사후조건** | 유저의 보유 코인이 차감되며, 해금된 캐릭터 소유 정보가 인게임 데이터에 업데이트된다[cite: 12]. |

### 3) UC-03: 오답 교정 가이드 확인
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-03: 오답 교정 가이드 확인[cite: 12] |
| **액터명** | 주 액터: 아동 / 초등 저학년 (서브 액터: 일반 유저)[cite: 12] |
| **개요** | 게임 플레이 중 369 및 수 연산 오답이 발생했을 때, 시각적 원 세기 및 묶음 힌트 레이어를 오버레이하여 직관적인 피드백을 제공한다[cite: 12]. |
| **사전조건** | UC-01 진행 중 유저의 369 및 연산 오답 또는 타임아웃 예외가 발생해야 한다[cite: 12]. |
| **기본흐름** | 1. 오답이 발생하면 화면이 일시적으로 정지되며 오답 안내 연출이 재생된다[cite: 12].<br>2. 시스템이 해당 숫자의 369 여부 및 연산 힌트를 화면에 오버레이한다[cite: 12].<br>3. 유저가 오답 원인을 직관적으로 확인한다[cite: 12].<br>4. 가이드 확인 후 준비 카운트다운과 함께 게임 화면으로 복귀하거나 판을 재시작한다[cite: 12]. |
| **대체흐름** | **[대체흐름 3A: 일반 모드 빠른 스킵]** 일반 유저 모드일 경우 가이드 연출 시간을 축소하여 빠른 재도전을 유도한다[cite: 12]. |
| **예외흐름** | **[예외흐름 3E: 연속 오답 발생]** 동일 구간에서 연속 3회 이상 오답 발생 시 기초 수 연산 힌트의 시각적 강조 효과를 극대화하여 표시한다[cite: 12]. |
| **사후조건** | 유저의 오답 이력이 플레이 기록 데이터에 집계 및 반영된다[cite: 12]. |

### 4) UC-04: AI 봇과 대전
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-04: AI 봇과 대전[cite: 12] |
| **액터명** | 아동 / 초등 저학년, 일반 유저[cite: 12] |
| **개요** | 유저가 인공지능 봇(미소, 비비, 보모 등)과 함께 턴을 교대하며 타임어택 대전을 수행하는 모듈[cite: 12] |
| **사전조건** | 싱글 플레이 메뉴에서 AI 대전 모드 선택 완료[cite: 12] |
| **기본흐름** | 1. 유저가 AI 봇 인원수(1~3명) 및 난이도를 선택하고 게임을 시작한다[cite: 12].<br>2. 시스템이 플레이어와 AI 봇의 턴 순서를 배정하고 화면에 표시한다[cite: 12].<br>3. 턴을 진행하며 유저 및 AI 봇이 정해진 시간 내에 입력을 제출한다[cite: 12].<br>4. 한 플레이어의 턴이 완료되면 다음 순서로 턴을 동기화하여 전환한다[cite: 12].<br>5. 최후의 1인이 남거나 게임 목표 달성 시 대전 결과를 출력한다[cite: 12]. |
| **대체흐름** | 해당 없음[cite: 12] |
| **예외흐름** | **[예외흐름 4E: AI 봇 오답 발생]** AI 봇이 난이도 확률 알고리즘에 의해 오답을 내거나 시간 초과될 경우 하트가 차감되고 턴이 스킵된다[cite: 12]. |
| **사후조건** | 대전 순위 산출 및 순위에 따른 보상 코인 지급[cite: 12] |

### 5) UC-05: 플레이 기록 조회
| 항목 | 내용 |
| :--- | :--- |
| **유스케이스명** | UC-05: 플레이 기록 조회[cite: 12] |
| **액터명** | 아동 / 초등 저학년, 일반 유저, 학부모 / 교육자[cite: 12] |
| **개요** | 유저 및 학부모/교육자가 최고 점수, 플레이 횟수, 오답 노이즈 데이터 등 플레이 기록 및 학습 현황을 조회하는 기능[cite: 12] |
| **사전조건** | 메인 화면 또는 마이페이지 메뉴진입 완료[cite: 12] |
| **기본흐름** | 1. 액터가 '플레이 기록' 또는 '학습 현황' 메뉴를 선택한다[cite: 12].<br>2. 시스템이 저장된 인게임 데이터(최고 정답 기록, 모드별 진행도, 수 연산 정확도)를 호출한다[cite: 12].<br>3. 화면에 직관적인 통계 UI 및 라벨 형태로 플레이 기록을 렌더링한다[cite: 12]. |
| **대체흐름** | 해당 없음[cite: 12] |
| **예외흐름** | **[예외흐름 5E: 플레이 기록 부재]** 신규 유저로 플레이 기록 데이터가 없는 경우 기본 안내 문구("플레이 기록이 없습니다")를 표시한다[cite: 12]. |
| **사후조건** | 기록 조회 완료 후 이전 화면으로 복귀[cite: 12] |
